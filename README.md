# Teachers' Day Message Card

A personalized, animated Teachers' Day message card built with **HTML, CSS, and JavaScript**.

## Features

- 📖 Book-style 3D flip/open animation
- ✨ Floating sparkle effects and celebration burst
- 💌 Customizable teacher name, sender name, and message
- 🖼️ Add or replace the teacher photo directly in the browser
- 🎵 Optional audio upload and playback
- 🎨 Custom accent color
- 📱 Responsive layout for desktop, tablet, and mobile
- ⌨️ Keyboard controls: **Left Arrow** / **Right Arrow** and **Esc**
- 🧾 No framework or build process required
- 🔒 Uploaded photo/audio are handled locally in the browser during the session

## Included Files

- `index.html` — webpage structure and card controls
- `style.css` — design, responsive layout, animation, and book effect
- `script.js` — interactivity, customization, photo/audio handling, and effects
- `teacher-photo.jpg` — sample/default teacher photo supplied for this project
- `README.md` — project description and instructions

## Default Message

> Happy Teachers’ Day! Thank you for your patience, guidance, and dedication. Your lessons inspire us to learn, grow, and become better every day. We truly appreciate everything you do! ❤️📚

## How to Run

1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open `index.html` in a modern browser.
4. Click **OPEN THE CARD**.
5. Click **Customize Card** to edit the message, teacher name, sender name, photo, audio, caption, and accent color.

### Adding a Photo

Use **Customize Card → Add / replace photo**. Select a JPG, PNG, WEBP, or another browser-supported image.

### Adding Audio

Use **Customize Card → Add optional audio**. Select an MP3, WAV, OGG, or another browser-supported audio file. Tick **Play attached audio** if you want it to start when the card opens. Some browsers require a user click before audio can play.

## GitHub Pages

After creating a public GitHub repository:

1. Upload `index.html`, `style.css`, `script.js`, `teacher-photo.jpg`, and `README.md`.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.
6. Your card can then be shared using the GitHub Pages URL.
